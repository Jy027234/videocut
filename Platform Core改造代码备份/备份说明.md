## 改造目标

解除视频剪辑工具组 P0 阶段的 `live_byte_service_smoke` 阻塞点：Platform Core 需要提供受租户与服务账号授权保护的 artifact bytes endpoint，让外部 video-toolkit worker 可以通过 `artifact_ref.download_url` 拉取输入素材 bytes。

## 核心新增能力

```text
POST /toolkit-artifacts
GET  /toolkit-artifacts
GET  /toolkit-artifacts/{artifact_id}
GET  /toolkit-artifacts/{artifact_id}/bytes
```

新增能力覆盖：

```text
- toolkit_artifacts 表和 Alembic 迁移
- inline artifact bytes 存储
- artifact_ref 生成，包含 checksum 和相对 download_url
- 租户隔离
- 用户 bearer 与服务账号 token 鉴权
- toolkit.artifacts.read / toolkit.artifacts.write 权限
- video-editing-toolkit 默认 Tool Catalog 条目
```

## 后续接入建议

```text
1. 在云端 Platform Core 应用本备份中的模型、schema、路由、seed、迁移和测试改造。
2. 执行 Alembic upgrade head，确认 toolkit_artifacts 表创建成功。
3. 为 agentctl / video-toolkit worker 签发带 toolkit.artifacts.read 的服务账号。
4. 通过 POST /toolkit-artifacts 登记视频输入素材，取得 artifact_ref。
5. 让 video-toolkit worker 使用 artifact_ref.download_url 与服务账号 token 拉取 bytes，完成 live_byte_service_smoke。
```
